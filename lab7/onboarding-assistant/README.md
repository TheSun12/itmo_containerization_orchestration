# Project X — сервис аналитики

Микросервис на Python (FastAPI). Собирает события от клиентов и складывает в ClickHouse.

## Быстрый старт
`make dev`

## Структура
- `src/` — код приложения
- `docs/` — документация
- `config/` — конфигурации окружений
- `scripts/` — вспомогательные скрипты
